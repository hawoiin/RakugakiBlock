# らくがきブロック v20.141 — 洞窟拡張

- v20.138 を基準に、既存の自然テーマ洞窟と東側拡張を維持。
- 拡張区画は地表から最低2ブロックを残す高さで生成し、地表の穴を避ける。
- クライアントとサーバーで同一の座標・生成規則を使用。
- 保存済み v2 洞窟は追加区画だけを移行。拡張予定地にブロック変更がある場合は上書きせず導入を見送る。
- 胞子吐きが洞窟内の歩行可能な通路をゆっくり徘徊し、壁・床・天井を避けるサーバー側経路探索を追加。プレイヤーを感知すると停止して胞子攻撃し、ペン突き後はひるんでから再び移動する。
- 胞子吐きの移動アニメーションと南側小部屋のプレイヤー検出範囲を更新。洞窟地形、胞子吐きの造形、ペン突き、胞子弾・胞子雲の基本仕様は維持。

## Render

GitHub リポジトリのファイル一式を更新してコミット／プッシュし、Render の再デプロイを実行してください。参加者は `Ctrl+F5` で再読み込みしてください。


## v20.141 ペンの持ち方
- ペンスロットで色を選択中は、アバターの右手に鉛筆モデルを常時表示。
- 右手の手のひら位置にペンを合わせ、前下向きに傾け、簡易グリップ形状を追加。
- 一人称視点では画面右下に前腕・手・鉛筆を表示。
- 選択中のペン状態を位置通信に追加し、他の参加者にも表示を同期。
- ペンを選んでいない場合、または消しゴム選択時は持ち物を非表示。


## v20.141 洞窟の下層
- 既存洞窟の東南端から下り階段を追加し、地下主広間と北側の隠し小部屋へ接続。
- 地表の岩盤・階段床を移行時に検査し、建築やブロック変更がある位置には自動追加しない。
- 既存の胞子吐きAI・ペン操作・地上地形は変更なし。
