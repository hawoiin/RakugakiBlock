# らくがきブロック v20.138 — 洞窟拡張

- v20.137 を基準に、既存の自然テーマ洞窟を残して東側へ通路・主空洞・北側の小部屋を追加。
- 拡張区画は地表から最低2ブロックを残す高さで生成し、地表の穴を避ける。
- クライアントとサーバーで同一の座標・生成規則を使用。
- 保存済み v2 洞窟は追加区画だけを移行。拡張予定地にブロック変更がある場合は上書きせず導入を見送る。
- 胞子吐き、ペン突き、胞子雲、既存の地上要素は変更なし。
