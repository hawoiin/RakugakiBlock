# v20.136 — 洞窟限定「胞子吐き」

- 自然テーマの v20.133 洞窟が存在するときだけ、東側の鉱脈通路に敵「胞子吐き」を配置。
- プレイヤーが洞窟内で近づくと、約1秒の予備動作後に胞子弾を発射。ブロックやプレイヤーに当たると短時間の胞子雲になる。
- 胞子雲に入ると移動速度が一時的に低下。雲から離れた後も効果は短時間残る。
- 色付きペンを選び、敵に照準を合わせて近づいてクリックすると、ペンで突いて短時間ひるませられる。ダメージや撃破は発生しない。ブロック選択中・消しゴム選択中は突けず、通常の設置／消去操作を維持する。
- 敵・弾・雲の状態はサーバーで管理し、参加者全員へ同期。ペン突き動作も同期する。
- 洞窟のないテーマや、洞窟形状を含まない読み込みワールドには敵を出さない。

## 起動
ZIPを展開し、`start.bat` でローカルサーバーを起動してください。

## 確認状況
JavaScript 構文、ZIP 整合性、サーバー側の洞窟検出・胞子挙動・ペン突き判定・レート制限の静的確認を実施。ブラウザでの実描画や複数参加者接続の実機テストは未実施です。
